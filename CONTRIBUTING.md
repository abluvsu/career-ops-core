# Contributing to Career Ops Core

Thank you for your interest in contributing to **Career Ops Core**! 

Career Ops is an open-source, privacy-first career automation system designed to eliminate resume fabrication, enforce mathematical formatting precision (exact 2-page fit, zero orphan lines, ATS keyword density), and empower job seekers through autonomous agent workflows.

---

## 1. Core Principles

1. **Privacy-First (Dual-Repository Law)**:
   - **Never commit personal or identifiable candidate data** (names, phone numbers, personal emails, specific private compensation, unverified claims) into this core repository.
   - Core files must remain 100% generic, reusable, and parameterized.
   - Personal candidate data belongs strictly in private repositories (`career-ops-<name>`).

2. **Deterministic Quality Control**:
   - Resumes generated by the engine must be mathematically constrained:
     - Exact 2-page physical geometry (no 3rd page overflow).
     - Character budgets (95–115 or 180–230 characters per bullet) to prevent widow/orphan lines.
     - Strict ban on unescaped hyphens/dashes in dynamic prose (Rule 2).
     - Unicode en-dash (`–`) strictly enforced for date spans.

3. **Type Safety & Testing**:
   - Zero `any`. Runtime validations must use `zod`.
   - All tests must pass: `npm test` (10/10 tests in `templates/engine.test.js`).

---

## 2. Development Setup

### Prerequisites
- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher
- **Python** (optional, for WeasyPrint): Python 3.10+ with `weasyprint` installed (`pip install weasyprint`)
- **Puppeteer** (fallback PDF generator): Included in `devDependencies`

### Getting Started

```bash
# 1. Fork the repository on GitHub
# 2. Clone your fork
git clone https://github.com/<your-username>/career-ops-core.git
cd career-ops-core

# 3. Install dependencies
npm install

# 4. Run the test suite
npm test
```

---

## 3. How to Add or Improve Agent Skills

Agent skills live in `.agents/skills/<skill-name>/` and must follow the Antigravity Skills specification:
- Every skill folder must contain a `SKILL.md` file with YAML frontmatter (`name`, `description`).
- Skills must be candidate-agnostic and focus on generic career operations (e.g. ATS optimization, salary negotiation, STAR interview prep).
- Do not hardcode specific candidate company names, degrees, or URLs in skill instructions.

---

## 4. Submitting Pull Requests

1. Create a descriptive feature branch:
   ```bash
   git checkout -b feature/improved-widow-checker
   ```
2. Make your modifications cleanly.
3. Run test suites to ensure zero regressions:
   ```bash
   npm test
   ```
4. Commit your changes following conventional commits:
   ```bash
   git commit -m "feat(templates): enhance WeasyPrint visual fit guard"
   ```
5. Push to your fork and open a Pull Request against the `master` branch of `abluvsu/career-ops-core`.

---

## 5. Security & Responsible Disclosure

If you discover any security vulnerability or personal data leakage within the core templates, please open an issue or contact the maintainers directly.
